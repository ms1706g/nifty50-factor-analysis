# nifty50-factor-analysis
A quantitative market data analysis project studying equity return behavior, volatility clustering, and correlation dynamics for NIFTY 50 stocks. Implements simple momentum and volatility factors using Python with an emphasis on data quality, interpretability, and investment relevance across multiple market regimes (2018-2024).

# Factor-Based Return & Volatility Analysis on NIFTY 50

## Objective
To analyze equity return behavior, volatility dynamics, and simple
factor characteristics for major Indian stocks across multiple
market regimes.

## Data
- Daily adjusted equity prices
- Source: Yahoo Finance (yfinance)
- Period: 2018–2024

## Methodology
- Computed daily returns and rolling volatility
- Constructed simple momentum and volatility factors
- Analyzed correlation behavior across stocks
- Focused on interpretability and signal stability

## Key Observations
- Volatility exhibits clustering and regime-dependent behavior
- High-momentum stocks often carry higher short-term risk
- Correlations increase during market stress, reducing diversification

## Limitations & Future Scope
- No transaction costs or liquidity constraints
- No strategy backtesting or return forecasting
- Future work may include factor backtesting and risk-adjusted metrics
